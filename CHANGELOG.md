# Журнал изменений

## 1.0.0 - Не выпущен

- Для Chart добавлены рамки и цвета подписей, цвет рамки и цвет втулки
  измерительной диаграммы.

- Добавлено сохранение BackColor для Chart, PivotChart, GanttChart и
  Dendrogram с проверкой связанных записей цвета.

- Добавлено сохранение рамки TextDocumentField и цвета рамки
  HTMLDocumentField, GeographicalSchemaField и GraphicalSchemaField.

- Для TrackBar добавлено сохранение LargeStep и MarkingStep с проверкой
  допустимых целых значений.

- События сохраняют имя действия и независимые локализованные Text,
  ToolTip и Description, включая значения, назначенные в Designer.

- Добавлен именованный тип реквизита valueTree и распознавание GUID
  известных типов коллекций без учета регистра.

- Добавлено сохранение пяти событий GanttChart, HTMLDocumentField,
  GeographicalSchemaField и GraphicalSchemaField.

- Для Dendrogram добавлено сохранение событий Selection и DetailProcessing.

- Для Chart добавлены локализованные форматы подписей значений и процентов
  с точным сохранением переносов строк.

- Для Chart добавлены разделитель подписей, пределы количества серий,
  углы и толщина элементов измерительной диаграммы.

- Для Chart добавлено сохранение событий Selection и DetailProcessing.

- Для Chart добавлено 13 булевых свойств с учетом размеров диаграммы
  и связанных полей автоматических пределов.

- Для Form добавлено сохранение 12 событий вместе с ранее поддержанным OnClose.

- Для SpreadsheetDocumentField добавлены восемь свойств и семь событий
  с проверкой связанных полей полос прокрутки.

- Для вложенной Panel добавлены общие свойства, все 13 режимов ShowTabs
  и событие OnCurrentPageChange.

- Для PictureDecoration добавлены четыре события перетаскивания, для
  ListBox добавлены события выбора, активизации строки и изменения флажка.

- Для Table добавлены семь цветов и два шрифта с индивидуальными
  типизированными значениями по умолчанию.

- Для Table добавлено сохранение 11 булевых свойств отображения,
  изменения колонок и перетаскивания.

- Для Table добавлено сохранение 21 именованного события.

- Для InputField и ChoiceField добавлено сохранение 16 событий выбора,
  изменения и настройки через общую коллекцию именованных событий.

- Для Table добавлены Enabled, ToolTip, Font, BorderColor и FieldBackColor
  через общий механизм свойств элементов.

- Для LabelDecoration добавлены VerticalAlign, MarkNegatives и ScrollingText
  с проверенными значениями и значениями по умолчанию.

- Некорректный UTF-8 в модуле Form.bin отклоняется при чтении и записи с
  диагностикой `OOF1204`; корректный Unicode и BOM сохраняются.

- JSON-диагностика CLI сохраняет корректный Unicode и явно отображает
  некорректные байты аргументов и путей.

- Команды build и dump отклоняют выходные пути, совпадающие с используемыми
  входными файлами, в том числе через символические и жесткие ссылки.

- Добавлены Hyperlink надписи и Shortcut для надписи и картинки.

- Добавлено сохранение именованного обработчика PictureDecoration.Click.

- Добавлено сохранение именованного обработчика LabelDecoration.Click.

- Добавлено сохранение Form.AutoTitle как булевого свойства формы.

- Добавлено свойство CheckBox.ThreeState с булевым значением и проверенным
  значением по умолчанию false.

- Добавлены именованные переводы Caption самой формы; AutoTitle остается
  отдельным неподтвержденным свойством.

- Добавлены именованные переводы Caption для Button, CheckBox, RadioButton,
  UsualGroup и LabelDecoration.

- Именованные переводы ToolTip распространены на 14 типов обычных элементов;
  прежние ограничения редакторов колонок таблицы сохранены.

- Для NonselectedPictureText добавлены именованные переводы с ограничением их
  числа. Пустые переводы сохраняются в модели, но Designer может удалить их
  при выгрузке, что остается видимым в различиях XML.

- Для цели 8.5.1.1343 явно исключен ActiveXControl; добавлен отчет `oof --coverage --json`, отделяющий классификацию дескрипторов от проверки семантики.
- Добавлены CalendarField.ToolTip, CheckBox.BorderColor, ChoiceField.Font и CommandBar.Font через общие кодеки; значения проверены getters и строгим Designer.
- Добавлены RadioButton.Font/BorderColor, InputField.Font/BorderColor и ListBox.BorderColor; сохранены профили типов, привязок и редактора таблицы.
- Общие Font/BorderColor расширены на CalendarField, ProgressBar и UsualGroup; TrackBar поддерживает BorderColor. Учтен полужирный default UsualGroup и явно заданный bold автоматического шрифта.
- Добавлены 35 цветовых свойств через общий именованный кодек; восстановлено чтение известных typed defaults перечислений, рамки, сочетания клавиш и SelectionValue.
- CalendarField сохраняет конец периода отображения и четыре флага поведения; CurrentDate явно классифицирован как временное значение. Исправлено чтение именованных style defaults цвета и нормализация default шрифта UsualGroup в XML.
- PictureDecoration сохраняет пять флагов, текст отсутствующей картинки и шесть режимов PictureSize; парные поля размера проверяются на совпадение.
- Добавлены ChoiceField.ChoiceListHeight/ChoiceListWidth и InputField.ChoiceListWidth со знаковым целым кодеком и проверкой границ; редакторы колонок таблицы не расширены.
- ChoiceField сохраняет флаги ChoiceButton, ClearButton, SpinButton, OpenButton и ReadOnly.
- CheckBox и RadioButton сохраняют HorizontalAlign, VerticalAlign и TitleLocation с подтвержденными доменами перечислений в API и XSD.
- Общая прозрачность расширена на CheckBox, ChoiceField, RadioButton, LabelDecoration и PictureDecoration; PictureDecoration также сохраняет Font и BorderColor.
- Добавлены прозрачность UsualGroup и TrackBar, показ процентов и стиль ProgressBar, ориентация обоих контролов и разметка TrackBar; перечисления ограничены в модели и XSD.
- Добавлены Border у 11 типов контролов с отдельным default и форматом UsualGroup, а также CalendarField.SelectionMode; SelectedDates явно исключен из сохраняемого XML как временная коллекция.
- Добавлен OnChange для CheckBox, RadioButton и TrackBar с проверкой ссылок, владельца и структуры действий.
- Добавлены все восемь именованных событий CalendarField с проверкой владельцев, дубликатов и структуры действий.
- Запись XML, модуля, ресурсов и BIN использует приватную подготовку файлов и откат при ошибке установки; существующие режимы доступа сохраняются.


- Добавлены библиотека `liboof` и CLI `oof` для команд `dump` и `build`.
- Обычная форма представляется именованной моделью, XML версии 2.1, модулем `Module.bsl` и файлами ресурсов.
- Реализованы чтение и сборка проверенных сочетаний контролов и свойств. Для неподдержанных данных выводятся предупреждения и признак `reconstructionComplete="false"`.
- Проверено чтение всех 38 контролов эталонной формы и прохождение собранной именованной проекции через строгий Designer. Это подтверждает полезную проекцию и ее повторяемость, но не полное восстановление произвольной формы.
- Целевая задача первой версии включает информационное сравнение доступных свойств. Отсутствие различий в XML само по себе не доказывает отсутствие изменений в исходном `Form.bin`.
- Ограничены размер входных файлов, глубина и число токенов, память и обход блоков контейнера. Модуль и картинки проверяются на принадлежность пакету; опасные символические и жесткие ссылки отклоняются.
- Закреплены версии GitHub Actions по хешам коммитов, ввод тега выпуска отделен от shell-кода и проверяется до использования.
- Исследовательские платформенные скрипты проверяют каталог вывода до создания, используют новые каталоги и передают значения в статический shell-код через аргументы.

Версия не готова к выпуску: `release_ready=false`, release-gate остается заглушкой. Текущий статус и ограничения указаны в [README](README.md) и [целевом состоянии](docs/repository-target-state.md).
